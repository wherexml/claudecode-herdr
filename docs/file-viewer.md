# 文件阅读器

Markdown 文本文件（.md、.markdown、.mdown、.mkd，扩展名不区分大小写）默认使用现有 Markdown 渲染器阅读，支持标题、列表、表格和代码块。右上角代码图标切换源码，眼睛图标返回渲染。每次打开文件默认渲染；其他文本文件仍保持原文预览。下载及新标签页继续提供原始文件。

沿用 256 KiB 文本预览上限和超限提示。Markdown 不执行原始 HTML，文件链接在当前机器上下文中读取，相对路径以当前文档目录为基准。渲染器与聊天共用；其支持范围不因文件预览而扩展。

验收：打开 Markdown 查看标题和表格；切换源码再切回；重新打开默认渲染；打开普通源码保持纯文本。证据保存在 evidence/file-viewer/。

## 文档翻译

文本文件标题栏显示与聊天翻译一致的黄色 Languages 图标。点击将当前预览内容翻译为中文，再点击切回原文；Markdown 仍按排版渲染。与聊天翻译开关独立，使用同一服务端翻译配置，不修改文件或下载内容。长文顺序分段翻译，代码围栏保持原文。关闭或切换文件/机器时取消请求，失败保留原文并允许再次点击重试。超出 256 KiB 的文件仅翻译当前预览部分，沿用截断提示。
